# Vishnu Cybersecurity & AI Portfolio

A modern portfolio website for an MSc Cybersecurity and AI student, built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Edit your details

Most profile content lives in:

- `data/profile.ts`
- `data/projects.ts`
- `data/writeups.ts`

## Deploy

Push this folder to GitHub, then import the repository into Vercel.
